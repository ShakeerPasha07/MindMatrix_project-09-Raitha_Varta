# Raitha-Varta – Agriculture Flash-Card Advisor

Raitha-Varta is an Android application that provides farmers with short and easy-to-understand agricultural tips through swipeable flash-cards.

## Features
- Flash-card UI using `ViewPager2`
- Crop category filters (Paddy, Areca Nut, Coconut, Tomato)
- Success stories for farmers
- Expert Ask feature using FAB
- Offline support with Room Database
- Image loading using Glide
- English and Kannada language support

## Technologies Used
- Kotlin
- Android Studio
- Room Database
- Glide
- ViewPager2

## How to Run
1. Open the project in Android Studio
2. Sync Gradle dependencies
3. Run on Emulator or Physical Device

## Project Structure
- `data/` → Database and DAO files
- `ui/` → Adapter and UI components
- `MainActivity.kt` → Main logic and filtering
- `res/layout/` → XML layout files
